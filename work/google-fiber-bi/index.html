Google Fiber · Business Intelligence Capstone

Understanding repeat customer calls

I built a dashboard and supporting documents to examine repeat customer-service calls in the Google Fiber capstone scenario.

Role
Capstone project

About the work

This capstone used a Google Fiber customer-service scenario to explore repeat calls. It was a learning project, rather than employment at Google Fiber.

The work connected a business question with requirements, data processing and dashboard design: which issues were leading to repeated calls, and how did those patterns vary across markets and time?

Defining what the dashboard needed to answer

I prepared a Stakeholder Requirements Document, a Project Requirements Document and a Planning Document. These set out the questions, requirements and planned work.

Working with the data

I used BigQuery, SQL, Tableau and Google Sheets for data processing and visualisation. The analysis examined call frequency, issue types and trends across markets and time periods.

Presenting the patterns

I designed dashboards that made repeat-call patterns easier to compare. The analysis also considered how those patterns could inform customer-satisfaction improvements within the scenario.

What this work involved

The project produced structured planning documents and dashboards that explained repeat-call patterns.

Tools and methods: BigQuery, SQL, Tableau, Google Sheets, Requirements documentation.
