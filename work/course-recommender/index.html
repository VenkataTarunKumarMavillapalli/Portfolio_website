Machine Learning Capstone

A course recommendation system

I explored different ways to recommend online courses from course content and enrolment data.

Role
Capstone project

About the work

This project looked at how a recommendation system could help learners find courses that interest them. I worked with online-course enrolment data and course descriptions, and compared content-based and collaborative-filtering approaches.

Understanding the data

I collected and explored the course enrolment data. I also represented course text using Bag of Words, which describes text through word occurrences, and used those representations to calculate similarities between courses.

Recommending from course content

I built content-based recommendation approaches using similarity measures, K-means clustering and principal component analysis. These approaches use the characteristics of courses to find related options.

Learning from enrolment patterns

I explored collaborative-filtering approaches using nearest neighbours, non-negative matrix factorisation, neural networks and regression and classification methods. I brought the work together in a presentation explaining the analysis and approaches.

What this work involved

The project compared several ways of making recommendations and presented the work as a capstone study.

Tools and methods: Exploratory data analysis, Bag of Words, K-means, PCA, Nearest neighbours, Matrix factorisation, Neural networks.
