About the work

This project explored the classification of fake and real news using natural language processing. I worked on the analysis of the text, the way it was represented for models, and the interface used to explore predictions.

The work compared traditional machine learning and deep learning models. It also explored how the choice of text representation affected classification.

Exploring the text

I examined readability, word co-occurrence, sentiment, named entities, topics and association rules. This helped describe the dataset before training models.

Comparing representations and models

I used TF-IDF and Word2Vec representations, and evaluated logistic regression, random forests, multilayer perceptrons, recurrent networks, transformers and a fine-tuned BERT model. I built preprocessing steps for tokenisation, vectorisation and padding so the models could handle texts of different lengths.

Building an interface for the results

I created an interactive Streamlit application that brought together multiple models and text-analysis features. It displayed predictions with confidence scores and sentiment categories, making the model outputs easier to inspect.

What this work involved

The project combined an analysis workflow, model comparisons and an interactive way to explore classification results.

Tools and methods: TF-IDF, Word2Vec, BERT, Neural networks, Text preprocessing, Streamlit.
