Azure AI Foundry + Semantic Kernel

Data Analyst Agent

I adapted an agent-based solution accelerator into an assistant with access to data tools and search.

Role
Independent implementation based on a solution accelerator

About the work

I replicated and customised an agent-based solution accelerator using Azure AI Foundry and Semantic Kernel. The work involved building an AI assistant and connecting it to the tools and services needed to handle analytical questions.

This was an adaptation of an existing accelerator. My work focused on customising the implementation and integrating the supporting services.

Connecting models and data tools

I used the Semantic Kernel Agent Framework with Azure AI Foundry, OpenAI and Llama models, and Azure Databricks plugins. Code Interpreter and Bing Search through Foundry Agent Tools supported grounding and reasoning during a session.

Managing user sessions

I worked with a Session Manager and WebSocket connections, and integrated Microsoft Entra ID for identity and Azure AI Content Safety for content checks.

Supporting the application

Azure Key Vault, API Management, Application Insights and Cosmos DB supported secrets management, service access, monitoring and application state. These services formed the infrastructure around the assistant.

What this work involved

The result was a customised agent-based assistant with data connections, session handling and supporting Azure infrastructure.

Tools and methods: Semantic Kernel, Azure AI Foundry, Databricks, Cosmos DB, Microsoft Entra ID, Key Vault, API Management, Application Insights.
