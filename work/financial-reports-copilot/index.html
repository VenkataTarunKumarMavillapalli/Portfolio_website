Copilot for Financial Reports

I adapted a retrieval-based AI assistant for finding and using information in financial reports.

Role
Independent implementation based on Microsoft’s Advanced RAG accelerator
View code on GitHub

About the work

I replicated and customised Microsoft’s Advanced RAG solution accelerator. RAG means retrieval-augmented generation: the application finds relevant information from documents and gives that information to a model to help it answer a question.

The implementation used Azure OpenAI and Azure Cognitive Search, with supporting services for document ingestion, sessions, authentication and monitoring.

Retrieving information from documents

I worked with GPT-4, Azure Cognitive Search and custom skills orchestration to build the knowledge retrieval assistant. The system combined document search with an AI-generated response.

Organising the application services

I implemented microservices for session management, query orchestration and document ingestion using AKS, Redis Cache and Azure Functions. Cosmos DB and Azure Storage supported persistent state and storage, while Key Vault handled secrets.

Configuring and monitoring the system

I integrated Microsoft Entra ID, API Management, Azure Monitor, Application Insights and Log Analytics. I also used a Configuration Service for runtime settings and automated evaluation through nightly test runs and logging flows.

What this work involved

The project brought together document retrieval, application services and operational tooling in a customised version of the Microsoft accelerator.

Tools and methods: Azure OpenAI, Azure Cognitive Search, AKS, Azure Functions, Redis, Cosmos DB, Key Vault, Azure Monitor.
