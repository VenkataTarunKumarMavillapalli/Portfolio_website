# Before publishing

This is a public personal portfolio, not an official WFP website.

- Review the full professional name, role wording, all dates, organisation names, education descriptions and contact email. Confirm that a 2026 edition showing 27 years is the intended framing.
- Review the high-level descriptions of WFP and EFSA work and obtain any internal clearance that applies to your situation. The code does not establish that any organisation has approved publication.
- Confirm that contributions are described accurately as individual work within team settings. No unsupported “world first,” promotion, institutional endorsement or numerical performance claim has been added.
- Verify the exact LinkedIn and GitHub profile URLs before adding them. Blank values intentionally create no links.
- Add personal memories or photographs only when supplied and chosen for public use. The current early-life chapter does not invent childhood events. Do not upload family photographs or third-party images without an appropriate basis for publication.
- Keep all demonstration records synthetic. Do not replace examples with real case information, internal exports, meeting content, system endpoints, API keys or screenshots of internal applications.
- Remember that all files in the publishing directory—including comments, JavaScript data, downloads and documents—can be publicly retrieved. Hiding content in the interface does not make it private.
- Keep the independent-personal-site disclaimer visible. The delivered site does not use UN, WFP, EFSA or university logos.
- Open the final site on the actual devices you expect visitors to use, including Safari on an iPhone. Test touch navigation, motion controls, project dialogs, contact links and the browser’s print function.
- After GitHub publishes, test both the homepage and a repository-subpath URL. Check that assets, downloads and the script-free profile load. No live GitHub deployment was performed in the delivery session.

## Information deliberately omitted

Precise birth date, telephone number, home address, private work endpoints, confidential case volumes, case identities, sensitive investigations, internal architecture details, colleague names, non-public research results and unverified professional profile URLs.

## Demonstrations are not production systems

The knowledge miniature has three predefined source-backed answers. The analytical miniature computes metrics from a fictional dataset. The evidence miniature is a synthetic timeline. The workflow miniature is a timed state machine with an explicit human-review button. The archive guide is a local keyword matcher. None of these features calls a model, accesses WFP data or operates an actual investigation workflow.
