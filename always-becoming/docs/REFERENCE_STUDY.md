# Reference study

Official reference supplied by the owner: https://www.enkiswebstudio.com/

Desktop live-browser inspection, 8 November 2026. No code or proprietary assets were copied.

## Observed

- Nearly monochrome editorial hero: huge tightly spaced headline, small metadata, asymmetric negative space, hairline rules, underlined call to action and a restrained rounded contact control.
- Scattered, rotated words assemble into a readable About paragraph as scrolling progresses.
- A full-screen night-city silhouette composition holds while the Understand / Design / Build captions and a small index change.
- Compact sticky identity and outlined menu replace the initial navigation. The menu uses large numbered text rows and fine separators.
- Service panels stack/slide over prior panels. Oversized typography creates breaks in pace.
- Depth is concentrated in the night-city composition and a shaded extruded logo. A small cyan pointer glow is the strongest color accent.

## Principles used in this original project

One dominant composition per scene; quiet navigation; controlled contrast and typographic scale; purposeful transitions; depth concentrated in memorable environments; meaningful interactions rather than random animation or repetitive glass cards. The life-story structure, artwork, geometric transformations and interactions are original to this portfolio.

Instagram reels were not inspected. No claim is made that a reel's implementation, assets or source code were verified. The reference's mobile behavior was not inspected.
